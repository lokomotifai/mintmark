## Becoming a maintainer

There is no fixed contribution count. The path is sustained, accurate work in a
scope, followed by an invitation to review in that scope, followed by an
invitation to maintain it. The first additional maintainer changes the merge rule
described in [GOVERNANCE.md](GOVERNANCE.md), which is the main reason the
invitation is taken seriously.
