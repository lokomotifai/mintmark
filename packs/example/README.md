# Example fixture pack

This pack exists for the quickstart, the test suite, and `packcheck` self-tests.

**It is not a sector pack.** Its two record types and single template set are the
smallest thing that exercises the contract end to end. Nothing here is modeled on
any real institution, and its distributions are illustrative rather than
researched. A sector pack lives in its own repository, carries its own governance
file set, and ships a versioned reference dataset; this does none of those things.
